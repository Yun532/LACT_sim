当前参数下的基底与示意数值
  • 位置 x/y 和 方向 dir_x/dir_y 共用所选输入坐标，但方向代表光子的传播方向，不是天空来向。
  • EventIO 2D 的 x/y 已相对各台望远镜，z=0 是记录面；默认再加局部 eventio_reference_z_m=-16。
  • u/v 不是阵列 x/y；它们是输出平面内积定义的二维轴。
  • pyLAST 输入适配把焦平面 u/v 映射为“仰角型 pix_x / 方位型 pix_y”；当前绘图函数按天空图习惯把 pix_y 放在横轴。
